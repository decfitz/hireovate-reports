# Hireovate client reports

Hosting for Hireovate client reports (decfitz.github.io/hireovate-reports for now; reports.hireovate.com once its DNS record is in place). Every report here is encrypted (AES-256-GCM, a separate random key per report). The keys are never stored in this repository or on the site: each one travels only in the link sent to the client, after the `#`, which browsers do not send to servers. Folder names are random and contain no client information. Search engines are blocked (robots.txt and noindex on every page). Reports are removed after 90 days.
